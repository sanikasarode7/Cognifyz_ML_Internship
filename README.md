# Cognifyz Technologies – Machine Learning Internship

## Overview

This repository contains the projects completed as part of my Machine Learning Internship at Cognifyz Technologies. The projects focus on restaurant data analysis, recommendation systems, and cuisine classification using Python and machine learning techniques.

## Internship Tasks

### Task 1: Predict Restaurant Ratings
**Objective:** Build a machine learning model to predict restaurant ratings based on available restaurant features.

**Work completed:**
- Data preprocessing and cleaning
- Categorical feature encoding
- Training and testing data split
- Regression model training and evaluation
- Model performance evaluation using Mean Squared Error (MSE) and R² score
- Analysis of features influencing restaurant ratings

**Folder:** `Task_1_Predict_Restaurant_Ratings/`

### Task 2: Restaurant Recommendation System
**Objective:** Develop a restaurant recommendation system based on user preferences.

**Work completed:**
- Restaurant data preprocessing
- Processing cuisine and price-related preferences
- Feature representation using TF-IDF and categorical encoding
- Similarity calculation using cosine similarity
- Generating restaurant recommendations based on user preferences
- Testing the recommendation function with sample preferences

**Folder:** `Task_2_Restaurant_Recommendation/`

### Task 3: Cuisine Classification
**Objective:** Build a classification model to predict restaurant cuisine categories using restaurant-related features.

**Work completed:**
- Data cleaning and preprocessing
- Handling infrequent cuisine categories
- Training and testing data split
- Classification model training
- Model evaluation using accuracy, precision, and recall
- Analysis of classification performance and challenges

**Folder:** `Task_3_Cuisine_Classification/`

## Technologies Used

- **Programming Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Machine Learning:** Regression, classification, feature encoding, model evaluation
- **Recommendation Techniques:** TF-IDF, cosine similarity
